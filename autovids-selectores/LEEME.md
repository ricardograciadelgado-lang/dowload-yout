# Selectores de AutoVids

`selectores.json` es la configuración remota que lee la extensión AutoVids (desde `remote-config.js`).
Solo añade formas extra de encontrar botones; si algo falla, la extensión usa sus reglas internas.

Para actualizar los selectores en todas las PCs, edita `selectores.json` aquí en GitHub y guarda los cambios.
